## Формула расчёта (Магазин, Премиум, Премиум+)

S = max(ширина × высота, 1 м²). Окно = S × (ставка профиля + надбавка стеклопакета) + фурнитура створок; монтаж = max(S × 1 600, 2 800); подоконник 550/700 ₽/пог. м; отлив 350 ₽/пог. м; откосы 900/1 100 ₽/пог. м по периметру (ширина + 2 высоты); москитка 800 ₽ за открывающуюся створку; демонтаж 600, вывоз 400, этаж без лифта 150 за этаж с 3-го. Профили, ₽/м²: EXPROF 58 — 3 600, KBE 70 — 4 400, REHAU Grazio — 5 300, VEKA Softline 70 — 5 700, VEKA Softline 82 — 8 200; ламинация +15%. Стеклопакет: 1-кам 0, 2-кам +600, энерго + аргон +1 500. Створка: глухая 0, поворотная 1 900, п/о 2 900. Контрольный пример: двустворчатое 1300×1400, KBE 70, 2-кам, п/о + глухая, подоконник, отлив, монтаж, 1 сетка ≈ 16 900 ₽. Ставки — демо, подробности в `docs/analiz-konkurentov.md`, раздел 3.3.
